# pull👙 — HOOKUP • CONNECT • FUN

An international adult connection platform in development.

## Product direction
- Adults 18+ only, with robust age assurance required before member access.
- Worldwide discovery with country and city-level controls; no public precise location.
- Clear intentions, mutual interest, privacy, consent and safer conversations.
- Initial market focus: United States, United Kingdom, Canada and Europe, with other regions subject to local law and platform requirements.

## Current repository
- Next.js 14, React 18, TypeScript and Tailwind CSS foundation.
- Responsive landing page and draft safety, privacy and terms pages.
- Join and login preview pages (not connected to authentication).
- Discovery and profile-builder previews using fictional sample profiles only.
- No production accounts, real member data, messaging, matching, age verification or payments are active.

## Development principles
1. Never admit minors; age assurance must be implemented and reviewed before launch.
2. Build blocking, reporting, moderation, anti-scam controls and abuse rate limits into the product.
3. Minimise personal data, protect it in transit and at rest, and provide deletion/export controls.
4. Review applicable privacy, consumer, dating-service and app-store rules in every launch market.
5. Confirm payment-provider acceptance before implementing subscriptions.

## Run locally
```bash
npm install
npm run dev
```

This repository is a development preview, not a live dating service. All sample profiles are fictional.
